# Origin of Technical

- Technical does not come from technology.
- It is derived from greek word 'techne' which usually means technique, skill, art, craft or method.

# Scope of Technical

- Technical means technique which can be applied to :
  1. Engineering
  2. Medicine
  3. Humanities
  4. Commerce
  5. Applied Arts

# What is Technical Writing ?

- Technical writing is an audience-centered means of communication that provides a reader with clear and easy access to information.
- Why does audience need the info ? - Because they are info deficient.
- Technical writing is the information written by experts for non experts.

Rule 1 : Level of language - Easy.
Rule 2 : Level of information - Depends on the end user.

Examples :
1. User manuals
2. Software installation guides
3. Assembling instructions
4. Legal disclaimers
5. Standard operating procedures
6. Reports
7. Service level agreements
8. Proposals
9. Catalogues
10. Press Releases

# Using class categories

- A class means a group, collection, category or set sharing similar characteristics or attributes.
- Examples of classes in analogous era :
1. Tool - Device
   a. usually without moving parts
   b. generally hand held
   c. used for manual work
2. Instrument - Device
   a. Contains sensitive material
   b. Measures and records
   c. Has calibrations / markings
   d. Distance related devices are included
   e. All musical devices are included too
3. Apparatus - A number of devices
   a. Assembled for a purpose
   b. Mostly in laboratories
   c. Can be a single device like test tube
4. Machine - Device
   a. Mechanical in nature
   b. Provides power as output
   c. Made of interacting components and parts
   d. Takes in one form of energy and converts
   e. Easy to identify as it has gears
5. Mechanism - Device
   a. A system like arrangement
   b. Manually operated
   c. Provides force or motion as output
   d. Works on the priciples of levers
6. Engine - Device
   a. Mechanical in nature
   b. Converts heat to mechanical energy
   c. Provides power to push
   d. Subset of machines
7. Appliance - Device
   a. Labour saving
   b. Used within four walls
   c. Provides creature comfort
   d. Mostly runs on electricity
8. Gadget - Device
   a. Electronic in nature
   b. Chip enabled
   c. Portable
   d. Has a luxury value
9. Device (generic)
   a. Generic term to be used rarely
   b. Only works with a qualifier
   c. Electronic / Electric / Mechanical

- Examples of classes in digital era :
1. Hardware - A physical component
   a. Electronic in nature
   b. Performs analog or logic operations
   c. Directed by software to execute any command
2. Software - Are sets of instructions
   a. Stored in the hardware
   b. Help run the hardware
   c. Transform inputs into outputs
3. Application - A software
   a. That performs a specific task
   b. Used only by end users
   c. Subset of software
4. Virtual Platform - A system
   a. Allows different applications to run
   b. Under the same environment
   c. Allowing users to access them via the internet
5. Cloud - A server or storage
   a. Accessed through the internet
   b. Provides IT services
   c. Storage, databases, computing power, etc.

# Inserting special notices

- It is important information readers must know in order to understand and accomplish tasks efficiently.
- It can prevent damage to equipment
- It can prevent damage to self and others
- There are 4 types of special notices :
  1. Note : It is a helpful hint, sometimes a tip, to help the user work more efficiently. Without a note, a user may lose precious time and get frustrated while trying to understand why something is not working.
  2. Caution : It warns readers about possible damage to equipment or data.
  3. Warning : It explains about the possibility of minor injury to the user or others around.
  4. Danger : Warns readers about the possibility of serious or fatal injury to themselves or others.
- Place the special notices exactly where needed.
- Use highlights like "bold", "italics" or "caps" to increase visibility
- Use standard color coding for each special notice.

# Writing user instructions

- The 4 parts of a user manual :
  a. General background of the product and its salient features
  b. Instructions to operate, maintain, repair, install, assemble, etc.
  c. Special notices like note, caution, warning and danger.
  d. Contact information of the manufacturer or service provider.
- Break up instruction into short, sequential and numbered steps.
- Pair instructions with well labeled images.
- Use heading and sub heading to guide the user.
- Insert visible special notices wherever necessary.
- Use the imperative style for framing instructions.
- Why the imperative style ?
  a. Impersonal
  b. Indirect
  c. Direct
  d. Imperative or command style

# Describing a process

- Define the process
- List all the materials required for the procedure
- Accompany all the numbered steps with a diagram
- Insert special notices in boxes, wherever necessary
- Use the imperative or command style for your instructions
