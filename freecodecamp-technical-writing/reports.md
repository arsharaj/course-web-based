# Introduction

- It comes from the Latin word "re" - back + "portare" - carry meaning "carry back".
- It carries the information that only you have.

# Classification of reports

1. By subject matter
   - Accounting
   - Finance
   - Engineering
   - Medicine
   - Other fields
2. By time interval
   - Periodic Reports
   - Monthly Bank Statements
   - Budget Reports
   - Report Cards
   - Special Reports
   - BE Project Reports
   - Covid Reports
3. By function
   - Informational : a presentation of facts on a subject
   - Examinational : a presentation of facts with analysis and interpretations.
   - Analytical : a presentation of facts with analysis, interpretations, conclusions and recommendations.
4. By formality
   - Formal
   - Informal
5. By physical factors
   - Memorandum format
   - Letter format
   - Short report
   - Long report or Book format report
6. By reader writer relationship
   - Administrative reports : Project report
   - Professional reports : NAAC accrediation report
   - Independent reports

# How to write a formal report

1. Prefatory part
2. Core part
3. Appended part

# Prefatory part
1. Title Fly
   - Title of the report where you can get creative
   - Fitting pictures but optional
   - Coloured but optional
   - Print on thicker quality paper
2. Title Page
   - Title of the report
   - Prepared for
   - Prepared by
   - Name of the organization and logo
   - Date of submission
3. Letter of Transmittal
4. Table of Contents
   - Mention all parts of the report
   - Mention page numbers
   - Front matter gets roman numerals
   - The body gets arabic numerals
   - Maintain numbering classification
   - Tab sub-sections inside
   - Double tab sub-sub-sections
   - Use APA style of referencing
   - Write all headings in the title case
   - Insert page numbers at the bottom
5. List of Illustrations
   - Use title case for all captions
   - Use the word figure for pictures
   - Table for matrix
   - Chart for all type of graphs
   - Label the 1st picture of Chapter 1 as Fig. 1.1.
6. Executive Summary
   - Single paragraph
   - Answer : Why, How and What
   - Don't user personal pronouns

# Core Part

The main body starts with the ..
1. Introduction
   - Formulaic sections :
     1. Origin of the report
     2. Purpose of the report
     3. The scope of the report
     4. Research question and hypothesis
     5. Limitations of the report
     6. Background of the report
     7. Sources and methods of data collection
   - Use third person always
   - Keep it brief
2. Specific Chapter Title
   - Follow the same sequence of headings and sub headings as mentioned in the TOC
   - Use the funnelling technique - general to specific
3. Survey Findings
   - Use a matrix to provide the survey description
   - Remember the caption of the table comes on the top of the table, for figures and charts it comes at the bottom.
   - Sections :
     1. Survey description
     2. Statistical analysis of the survey data
   - Start each question and the corresponding graph on a new page
4. Summary and Conclusion
   - The inferences drawn from the graphs, in a nutshell is the summary.
   - Answering the research question and proving the hypothesis is the conclusion.
   - Use bullet points for both summary and conclusion, if possible.
